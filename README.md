# Laboratorio 10
Henrry Manuel Cuti Sencia — Programación en Móviles — TECSUP.

Este repositorio contiene dos proyectos de Android Studio independientes. No abrir la carpeta raíz como si fuera un único proyecto Android.

- Lab10_Series: parte guiada y servidor Django en backend. Abrir Lab10_Series y ejecutar app.
- Bookshelf_Adicional: puntos adicionales Google Books. Abrir Bookshelf_Adicional y ejecutar app.

Cada proyecto tiene su propio settings.gradle.kts, build.gradle.kts, gradlew y módulo app. Ambos usan Java 17. Los applicationId son distintos y pueden permanecer instalados juntos.

El ejercicio del juego está en henrrycuti/umbra-unity, rama codex/lab10-api.
El código guiado se conserva. Google Books respondió HTTP 429 por cuota durante la comprobación real, como se registra en el informe.
