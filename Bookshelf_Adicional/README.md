# Bookshelf Adicional

Proyecto independiente de los puntos adicionales. Abrir esta carpeta en Android Studio y ejecutar la configuración app. Solo incluye la aplicación com.tecsup.bookshelf.

Usa Google Books por HTTPS y no necesita Django. La limitación HTTP 429 por cuota del servicio sigue documentada; separar los proyectos no elimina esa limitación externa.

Usar Java 17. Las pruebas de la capa de datos usan un servicio falso.
